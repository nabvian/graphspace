# Contributing to Graphspace

1. Create a focused change.
2. Add or update standard-library tests.
3. Run `PYTHONPATH=src python3 -m unittest discover -s tests -v`.
4. Run the CLI and benchmark when relevant.
5. Update API documentation for public changes.
6. Do not claim performance improvements without reproducible measurements.

Public API changes require a deprecation note or a major-version decision.
